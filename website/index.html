Works with Omni

OmniBots and Omni work together. Omni is the AI agent you talk to in your terminal, and it holds your AI provider keys and models. OmniBots uses the same ones, so Omi's team shares your providers, and you can add or edit a provider from either app (in OmniBots: Settings → Providers). Omni starts OmniBots for you: type /omnibots in Omni (/omnibots status and /omnibots stop too). Both live side by side in your user folder, ~\.omni and ~\.omnibots. So install Omni first, then OmniBots.

1 · Install Omni first

In PowerShell, paste this and press Enter:

irm https://omni.globalwarningnetworks.com/install.ps1 | iex

Then add your AI provider key in Omni. Everything about Omni is on its site: omni.globalwarningnetworks.com.

2 · Then OmniBots

Install OmniBots with the line below. Then start it from the Start menu, or type /omnibots in Omni.

No Omni? OmniBots still works on its own. It keeps its own provider list, in Omni's format, with your keys encrypted for your Windows account, never in a text file. Its doctor (Settings → Doctor, or ask Omi to call it) checks and repairs the setup of both apps: folders, providers, keys and dependencies.

Install

OmniBots is in active development. Install from the command line today; a one-click installer is coming.

One line in PowerShell

Open PowerShell (Windows key, type PowerShell, Enter), paste this, press Enter:

irm https://raw.githubusercontent.com/tattooinmtl/Omnibots/master/install.ps1 | iex

It checks for Python 3.12+ and Git (and offers to install them), downloads OmniBots into %USERPROFILE%\.omnibots (next to Omni's ~\.omni) with its own Python environment, and adds OmniBots to the Start menu, then runs its doctor to set everything up. Run the same line again to update; About → Check for updates tells you when there's a new version. Install Omni first: it holds your AI provider keys (why). Read the script first if you like.

Or install by hand 
git clone https://github.com/tattooinmtl/Omnibots.git
cd Omnibots
pip install -r requirements.lock
python -m omnibots

On first start OmniBots asks where your projects go (default C:\omnibots_output).
